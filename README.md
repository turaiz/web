# RAÍZ — web

Sitio público de RAÍZ viviendas industrializadas, publicado en https://turaiz.netlify.app.

Para cambiar precios, cuotas, agregados, WhatsApp o textos fijos, editar solo el bloque `CONFIG` al final de `index.html`. Netlify publica cada cambio de la rama `main` automáticamente.

Los costos, márgenes y documentos internos están en el repositorio privado `turaiz/comercial-finanzas`.
